Attack tests

Run on a private test chain (regtest) with the same code, because they need deliberately dishonest transactions. All were rejected.

  • Selling the same zote twice: a new transaction spending an already-spent zote was rejected by the node: ironwood double-spend: duplicate nullifier.
  • Fake successor: a forged note with the right hop number but not created in the spending action: FAIL successor is not in the spent carrier's Action.
  • Minting after the seal: FAIL mint_after_FINAL.
  • A lagging or dishonest server: FAIL RPC_SERVER_DISAGREEMENT, no result returned.
  • Wrong payment in a sale: the seller's tool refused to sign when the amount or recipient was changed.

On mainnet, the Try to cheat buttons test old, forged and wrong-key proofs live.

Superseded collection

The first mainnet collection's seal note was encrypted so that even the issuer's viewing key couldn't read it, so it can never verify as sealed. The bug was fixed and Lagos Lights replaced it. It stays here for completeness.

Cost

Everything above, including the superseded collection, cost about 0.0017 ZEC in network fees. Zotes themselves carry zero value; the sale moved 0.0002 ZEC from Kemi to Tobi.
